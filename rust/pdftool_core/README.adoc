== pdftool_core

Rust/WASM core for `+blocky-writer+`.

=== Current scope

* Exposes `+detect_blocks(pdf_data)+` for block metadata extraction
(placeholder output for now).
* Exposes `+fill_blocks(pdf_data, blocks, fields)+` for writeback
(currently passthrough).

=== Build

[source,bash]
----
wasm-pack build --target web --out-dir pkg
----
