== Claims, and where they are checked

[cols="1,2",options="header"]
|===
| Claim in the README | Where it is checked

| The Rust core has unit tests
| The source contains 22 test functions: 6 fill/error tests, 14 detector tests, and 2 numeric-geometry guard tests. PR #78 implementation commit `9f9370e` passed all three Rust checks in run `41326285595`; synthetic tests do not establish general PDF conformance or formal proof.

| `cargo fmt`, `cargo test` and `cargo clippy -D warnings` pass on the current implementation
| `.github/workflows/ci.yml`, job `Rust core (tests, formatting, lint)`. Run `41326285595` at `9f9370e` passed formatting, all 22 tests, and Clippy. Main baseline run `38818494415` at `3fd5ba1` is separate evidence.

| The frontend is a prototype with no build pipeline
| There is no AffineScript compiler configuration and no JavaScript package manifest in the tree. `deno.json` was deleted by #43.

| `fill_blocks` performs AcroForm-aware writeback
| `apply_field_value` in `rust/pdftool_core/src/lib.rs`, dispatched on field type `Tx` / `Ch` / `Btn`.

| Errors carry structured codes
| `CoreErrorPayload { code, message, context }`; 23 unique `BW_*` codes in the current source (20 baseline, 3 new). `pdftool_core` is bumped to `0.2.0` for the breaking public contract change; owner compatibility review remains open.

|===
