== Claims, and where they are checked

[cols="1,2",options="header"]
|===
| Claim in the README | Where it is checked

| The Rust core is implemented and has unit tests
| `cargo test --manifest-path rust/pdftool_core/Cargo.toml --locked` — 6 tests, including AcroForm writeback for text/select and button widgets and the structured error taxonomy.

| `cargo fmt`, `cargo test` and `cargo clippy -D warnings` all pass
| `.github/workflows/ci.yml`, job `Rust core (tests, formatting, lint)`. As of 2026-09-27 this job is green on `main` at `e1b6225`.

| The frontend is a prototype with no build pipeline
| There is no AffineScript compiler configuration and no JavaScript package manifest in the tree. `deno.json` was deleted by #43.

| `fill_blocks` performs AcroForm-aware writeback
| `apply_field_value` in `rust/pdftool_core/src/lib.rs`, dispatched on field type `Tx` / `Ch` / `Btn`.

| Errors carry structured codes
| `CoreErrorPayload { code, message, context }`; 20 `BW_*` codes.

|===
